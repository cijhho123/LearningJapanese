# New resources

The queue of resources, links and material still to be archived and folded into the repo.

Anything here is a candidate, not a commitment - some will turn out to be redundant with what is
already stored, and some will not be licensed in a way that allows archiving. See
[CONTRIBUTE.md](CONTRIBUTE.md) for how an entry gets from this list into a topic folder.

## How to add an entry

One heading per resource, with enough detail that someone else could act on it without asking you
what you meant:

```markdown
## Name of the resource

https://example.com/

Which topic folder it belongs in, and why it is worth having. Anything known about the licence,
and any note on how to grab it - "GitHub Pages, clone the source rather than mirroring the site",
"the PDF is behind a form", and so on.
```
