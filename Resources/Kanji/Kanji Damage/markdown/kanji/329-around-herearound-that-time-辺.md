## Kunyomi

あた＊り |  this neighborhood, the vicinity (as opposed to far away or another 'hood)   
★★★☆☆  
---|---  
( この ) へん ( に )  |  one thing which is around here somewhere!!   
★★★☆☆  
( ｘｘｘ ) べ ( に )  |  BE is a SUFFIX, which can be put after any noun, meaning 'in the vicinity of': the ocean, the university, the table, etc. You can tell 'be' and 'hen' (above) apart because 'be' always comes after a proper noun- it's a SUFFIX. [SUF](../tags/37.html)
