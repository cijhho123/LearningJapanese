#  号 ID number

[口](9-mouth-small-box-radical-口.html) (mouth/small box radical) \+ [![](../assets/radsmall/capn-hook-5210d86fd223192de7a749f3f2694f35d11e1a70b5172ae682831b02f2fdedd6.jpg)](649-pirates-hook.html) (pirate's hook) 

★★★★☆

5 strokes

This is different from the related kanji 番 and 数! 号 doesn't refer to an individual number like 8 or 4. 号 refers to specific identification numbers: phone numbers, zip codes, pin codes for your ATM, etc. 

## Onyomi

GOU |  The apartment's ID number tells you which apartment to GO to.

## Jukugo

信号(しんごう) |  signal ★★★★☆   
[信](63-believe-信.html) (believe) + [号](656-id-number-号.html) (ID number) = 信号 (signal)  signal, i.e. traffic signal  
---|---  
暗号(あんごう) |  a code ★☆☆☆☆   
[暗](155-dark-暗.html) (dark) + [号](656-id-number-号.html) (ID number) = 暗号 (a code)   
暗証番号(あんしょう ばんごう) |  secret code number ★☆☆☆☆   
[暗](155-dark-暗.html) (dark) + [証](284-proof-証.html) (proof) + [番](395-number-番.html)[号](656-id-number-号.html) (number) = 暗証番号 (secret code number)  your secret PIN number you use when you go to the ATM. This is different from a password you use on the internet - that's パスワード。
