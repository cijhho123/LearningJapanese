## Jukugo

想像(そうぞう) する |  imagine ★★★☆☆   
[想](352-ideaimagination-想.html) (idea/imagination) + [像](1221-statue-image-像.html) (statue / image) = 想像 (imagine)  imagine. (imaginative： そうぞうてきな)  
---|---  
画像(がぞう) |  still image ★★☆☆☆   
[画](1039-a-drawing-画.html) (a drawing) + [像](1221-statue-image-像.html) (statue / image) = 画像 (still image)  image - usually it refers to an image on the computer screen which does NOT move (JPGs, basically).  
映像(えいぞう) |  image ★☆☆☆☆   
[映](406-project-reflect-映.html) (project, reflect) + [像](1221-statue-image-像.html) (statue / image) = 映像 (image)  any reflected, moving image - including images on TV or a computer screen, a shadow play, etc.
