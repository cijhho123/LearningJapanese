## Jukugo

格好(かっこう) |  looks ★★★★★ [1/2 KANA](../tags/31.html)   
[格](613-character-aspect-格.html) (character, aspect) + [好](7-like-好.html) (like) = 格好 (looks)  literally, 'look' or 'shape,' as in 'He's dressed as a woman' : おんなの格好してる。 But usually it means 'coolness:' かっこいい (cool) or かっこうわるい (not).(when used in the figurative, 'cool' sense, it is usually KANA)  
---|---  
性格(せいかく) |  personality ★★★★☆   
[性](475-sex-essential-nature-性.html) (sex / essential nature) + [格](613-character-aspect-格.html) (character, aspect) = 性格 (personality)   
合格(ごうかく) する |  pass test ★★☆☆☆   
[合](936-to-suit-合.html) (to suit) + [格](613-character-aspect-格.html) (character, aspect) = 合格 (pass test)  pass a test.(opposite： ふごうかく)
