#  物 animal / thing

[牛](1194-cow-牛.html) (cow) \+ [![](../assets/radsmall/thing-4c559fa5237751ad343fd364031b785b144576e13de9bac7183bcdb8fdd8a814.jpg)](1200-thing.html) (thing) 

★★★★★

8 strokes

[COCK](../tags/5.html)

This is one of the most useful kanji. But it's also one of the most disgraceful kanji when it comes to using KUNyomi in random jukugo. Like 50% of the time it'll use MONO instead of the onyomi. And even when it DOES use the onyomi, there's two onyomi which are ALSO used randomly. 

Fuck! 

On the good side, however, most of the 物 jukugo are so common that you'll pick them up in no time. 

Also worth mentioning, 物 refers to a physical thing, but the other 'thing' word (事; koto) refers more to actions or scenarios, states of mind, etc.

## Jukugo

買い物(かいもの) する |  shopping ★★★★★   
[買](533-buy-買.html) (buy) + [物](1201-animal-thing-物.html) (animal / thing) = 買い物 (shopping)   
---|---  
動物(どうぶつ) |  animal ★★★★★   
[動](1078-movement-動.html) (movement) + [物](1201-animal-thing-物.html) (animal / thing) = 動物 (animal)   
着物(きもの) |  kimono. ★★★★☆ [KUNKUN](../tags/13.html)   
[着](875-wear-arrive-着.html) (wear / arrive) + [物](1201-animal-thing-物.html) (animal / thing) = 着物 (kimono. )   
植物(しょくぶつ) |  plant ★★★★☆   
[植](1311-plant-植.html) (plant) + [物](1201-animal-thing-物.html) (animal / thing) = 植物 (plant)   
荷物(にもつ) |  luggage ★★★★☆ [FP](../tags/8.html)   
[荷](68-luggage-荷.html) (luggage) + [物](1201-animal-thing-物.html) (animal / thing) = 荷物 (luggage)  luggage or belongings. Also, cargo (if you're a ship's captain). Also, emotional baggage, or a metaphorical burden  
登場人物(とうじょうじんぶつ) |  character ★★★☆☆   
[登](1179-climb-登.html)[場](1208-place-場.html) (enter the stage) + [人](61-person-人.html) (person) + [物](1201-animal-thing-物.html) (animal / thing) = 登場人物 (character)  a character in a book, play, novel, movie, etc.  
本物(ほんもの) |  the real thing, not a counterfeit. ★★★☆☆ [KUNKUN](../tags/13.html)   
[本](338-book-the-real-本.html) (book / the real) + [物](1201-animal-thing-物.html) (animal / thing) = 本物 (the real thing, not a counterfeit.)   
博物館(はくぶつかん) |  museum ★★★☆☆   
[博](1017-museum-extensive-博.html) (museum /extensive) + [物](1201-animal-thing-物.html) (animal / thing) + [館](1614-big-hall-館.html) (big hall) = 博物館 (museum)  a natural history museum or aerospace museum. (fine-art museums are 美術館 （びじゅつかん））  
禁物(きんもつ) |  taboo or forbidden thing ★☆☆☆☆   
[禁](353-prohibition-禁.html) (prohibition) + [物](1201-animal-thing-物.html) (animal / thing) = 禁物 (taboo or forbidden thing )
