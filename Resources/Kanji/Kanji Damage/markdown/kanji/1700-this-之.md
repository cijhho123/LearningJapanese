#  之 this

☆☆☆☆☆

3 strokes

[SOLO](../tags/23.html)[PK](../tags/18.html)[OBSOLETE](../tags/55.html)

之 is an obsolete form of 'kore', meaning 'this'. - nowadays, これ is almost always written in kana! 

However, it's still useful as a radical, so you should learn it.
