[遣](../kanji/1617-apply-遣.html)(つかう) |  This is very specific. It means “to dispatch an envoy”. Or, to be careful or give consideration to. Usually only used with the phrase 気を遣う, but even then it’s usually hiragana so who cares. Good luck ever using that.
