# Sources and provenance - machine-readable kanji data

This file covers this folder's structured-data resources - the raw XML/JSON/CSV/TSV kanji datasets -
as opposed to the KanjiDamage mirrors, Heisig PDFs and Anki decks described in [`readme.md`](./readme.md).

Everything here was downloaded from its canonical upstream and unpacked; nothing is left compressed.
Total size: **~53 MB**.

## Flagged licence issues

1. **CJKVI IDS is GPLv2, the only non-Creative-Commons licence in either folder alongside the Shuowen Jiezi
   XML below.** For a private study repo this is unproblematic - GPL constrains *distribution*, not personal
   use, and it is data rather than linked code. If the local tutor tool distributes or embeds `ids.txt`,
   GPLv2's copyleft attaches; `elements.txt` (Kanjium, CC-BY-SA) and KRADFILE (EDRDG) cover most of the same
   ground with far weaker obligations.
2. **The JPDB kanji frequency list has no stated licence** - same situation as the word-frequency list
   described in `../Vocabulary/sources.md`. Scraped from jpdb.io, redistributed with a source link and
   nothing more. Fine for personal use; do not redistribute.
3. **Share-alike is contagious.** KANJIDIC2, KRADFILE/RADKFILE and Kanjium are CC-BY-SA or EDRDG-licensed.
   Any tool output that includes this data inherits share-alike plus the attribution notices above.
4. **`kradfile2` and `radkfile2` are copyright Jim Rose**, distributed alongside the EDRDG files but not
   under EDRDG's own copyright. If you attribute, name him for those two files specifically.
5. **`shinjitai-table`'s JSON files carry no explicit licence** (GitHub reports `license: null`, and there is
   no `LICENSE` file in the repo). The underlying facts - which kanji forms changed shape in 1949 - are
   drawn from a government table and are not copyrightable in themselves, but the specific compiled JSON is
   an unlicensed third-party artifact. Low risk for a private study repo; worth noting since this repo is
   public.
6. **The Ishizawa J-STAGE paper is freely *readable*, not confirmed freely *redistributable*.** J-STAGE's own
   terms put copyright with the publishing society/author and route reprint permission requests to them
   directly; there is no CC licence on the article. This is consistent with how this repo already treats the
   Heisig RTK volumes and the JapanesePod101 course (commercially/academically copyrighted material kept for
   personal study use), but unlike the CC-licensed data elsewhere in this folder, this one is not confirmed
   clear for redistribution.
7. **`swjz.xml` is GPLv2**, the same category as CJKVI IDS above - fine for personal use and for data
   rather than linked code, but copyleft attaches if it is ever redistributed or embedded in a tool.

| **`mifunetoshiro/kanjium` fonts** (ryakuji, MultiElements, Ultra-simplified) | same | Handwriting-abbreviation and component-lookup fonts; belongs in `../Writing/`. |
| **Official 常用漢字表 / 人名用漢字 PDFs** | <https://www.bunka.go.jp/> | The authoritative government designations, but as PDF prose rather than data; `../Writing/Official orthography/` already covers the orthography documents, and KANJIDIC2's `<grade>` field gives the same designations as a queryable integer. |
| **`scriptin/topokanji`** (topologically ordered learning lists) | <https://github.com/scriptin/topokanji> | A derived *ordering* rather than a dataset - kanji sequenced so components always precede the characters using them. Computable from KRADFILE plus the frequency data in this folder; left out as opinion rather than data, but worth a look for a study order. |
| **jiten.moe kanji frequency list** (CC-BY-SA 4.0, 3.2 billion characters across 16,368 titles) | <https://jiten.moe/frequency-dictionaries> | A JavaScript-rendered site whose download URLs are not present in the served HTML, so the data cannot be fetched non-interactively; accessible manually from a browser. |
| **kanji-database.sourceforge.net** (direct site) | <https://kanji-database.sourceforge.net/dict/swjz/> | Blocks scripted fetches - Cloudflare returns a bare `403` with a 2-byte `no` body regardless of User-Agent. Its data (説文解字注/Shuowen Jiezi) is GPL-licensed and mirrored verbatim on GitHub at `cjkvi/cjkvi-dict` (held above), which is not blocked. |
| **Academia.edu: "Identifying useful phonetic components of kanji"** | <https://www.academia.edu/5357025/> | Academia.edu gates full-text behind a signup/download flow that is not a stable, non-interactive route, and the platform is known for presenting paywalled or unclear-rights copies as freely downloadable. |
| **Kakihana et al., "Factors Relating to Kanji Reading Accuracy in Kun-readings"** | Wiley Online Library, *Japanese Psychological Research* | Subscription-paywalled, with no open-access edition available. |
| **Shirakawa Shizuka's 字統/字通** | (commercial dictionaries) | The other major modern source on kanji etymology, and arguably more relevant to Japanese specifically than Xu Shen's Chinese-focused Shuowen Jiezi - but these are commercial dictionaries from a still-in-copyright estate, with no free edition. `swjz.xml` (held above) is the free alternative in the same tradition: Xu Shen's 2nd-century source text via Duan Yucai's annotated edition, which Shirakawa's own work builds on and cross-references. |
| **National Archives (digital.archives.go.jp) scan of the 1946 当用漢字表** | <https://www.digital.archives.go.jp/item/971821> | A page-image scan of the Ministry of Education's original, with no text layer at all. Aozora Bunko's typeset PDF (held above) is more usable and is built from the same source document. |
| **Domain-specific kanji frequency** (legal/medical/technical/classical) | - | No free, citable corpus found in this category; most domain-specific frequency work is embedded in paywalled linguistics papers or proprietary corpora. A genuine, still-open gap. |
