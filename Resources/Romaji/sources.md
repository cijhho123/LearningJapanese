# Sources - Romaji / Japanese romanization

Provenance and licensing for the material in this folder.

The organising principle is **authority over popularity**: for romanization, the questions
people argue about on blogs are actually settled by a small number of primary documents - a
Japanese Cabinet Notification, a Library of Congress table, a BGN/PCGN agreement, a Ministry of
Foreign Affairs passport rule. Those are what this folder holds.

Total folder size: **~24 MB**.

## Caveats on the downloaded material

1. **The ALA-LC PDF is a scan with no text layer**, so it is not searchable and cannot be copy-pasted.
   It is the canonical file the Library of Congress links from its own index, so there is no better
   version available.
2. **The bunka.go.jp HTML pages are Shift_JIS, not UTF-8.** They render correctly in a browser
   (they declare their encoding) but if you process them with command-line tools you will need
   `iconv -f SHIFT_JIS -t UTF-8`.
3. **"ISO 3602 Strict = Nihon-shiki" is asserted in only one document here**, the IU conference
   presentation, which is explicitly a work-in-progress report rather than a peer-reviewed
   publication. The Agency for Cultural Affairs' own minutes say only that ISO 3602 is "close to,
   though not exactly the same as" the Cabinet Notification. Treat the equation as plausible and
   widely repeated, but not verified from a primary source in this folder.
4. **Most of the Japanese-government material is in Japanese only.** The 対照表 in the 2025
   notification and the tables in the Kimura papers are readable with minimal Japanese, since they
   are mostly romaji; the prose is not.
