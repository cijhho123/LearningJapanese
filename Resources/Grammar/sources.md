# Sources and provenance - machine-readable data in `Resources/Grammar/`

This file covers only the **structured data sets** added to this folder. The guides, books, site
mirrors and Anki decks that make up the rest of `Resources/Grammar/` predate this file and are
documented in [readme.md](./readme.md).

The point of these files is that the guide's grammar tables are hand-written and finite - a 20-row
conjugation map, a 30-pair transitivity table, a 13-verb keigo table. Everything below is the same
information as data you can query, join and diff, at 10-100x the coverage.

**Total size of the data sets in this file: 36.1 MB.** Retrieved 2026-09-17.

## Notes for actually using these

- **The jconj files are TAB-separated despite being named `.csv`.** `csv.reader(f)` will hand you
  one column. Use `delimiter='\t'`. Also: `kwpos.csv` has **no header row** - its first line is
  data. `conotes.csv` contains quoted fields with embedded newlines.
- `conjo.csv` keys on `pos` (the numeric id from `kwpos.csv`) × `conj` (the id from `conj.csv`) ×
  `neg` × `fml` × `onum`. `stem` is how many characters to strip; `okuri` is what to append.
- Kanjium's `conjugations.txt` has an FTS trick in its last column: readings are wrapped in `;`
  so you can substring-match a whole reading without a tokeniser.
- **The transitivity TSVs are a mechanical extraction from the source HTML**, not upstream
  files. The original HTML is kept beside them so the source of truth is intact. One real trap
  in the source: **two of Breen's five tables print INTRANSITIVE in the left column and
  TRANSITIVE in the right**, the opposite of the other three. The TSV normalises every group to
  transitive-then-intransitive; `pattern-groups-legend.txt` records the original column order per
  group along with Breen's verbatim group descriptions. A handful of intransitive headwords are
  kana-only in the source, so their `*_kanji` field is empty. All 267 data rows in the source
  table are accounted for; nothing was dropped.
- J-UniMorph feature abbreviations: `POL` polite, `FORM` formal, `COL` colloquial, `FOREG`
  foregrounded, `ELEV` elevating (sonkeigo), `HUMB` humbling (kenjougo), `PROSP` prospective,
  `OPT` optative, `OBLIG` obligative, `PERM` permissive, `INTEN` intentive.
- `grammar.json` IDs are stable slugs (`desu-polite-copula`, `da-plain-copula`) and
  `grammar-to-sentences.json` maps those IDs to Tatoeba sentence IDs, so the two join directly.
