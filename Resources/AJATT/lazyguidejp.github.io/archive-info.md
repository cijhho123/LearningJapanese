# Lazy Guide for Japanese Immersion (lazyguidejp.github.io) - rendered-site mirror

Source: <https://lazyguidejp.github.io/jp-lazy-guide/> (source repository:
<https://github.com/LazyGuideJP/lazyguidejp.github.io>).

A full mirror of the built site for the *Lazy Guide for Japanese Immersion*, taken to capture the
setup-screenshot images the markdown source references by path but does not itself contain. The
markdown source is deliberately duplicated between the two folders: `../lazyguidejp/` is the
plain-text source, this folder is the built HTML site with images.

## Contents

172 files, 48 MB: `assets/` (site CSS/JS), `img/` (122 setup-screenshot images and GIFs - Anki,
Yomitan, ShareX, mokuro, texthooker, and similar), and `jp-lazy-guide/` (the 45 rendered guide
pages, one per markdown source file).

## What was excluded

Three images present in the source repository's `docs/img/` - `microstep-v0.png`,
`microstep-v1.png` and `microstep-v2.png` - are not part of this mirror. The live guide links to
those directly on GitHub (`github.com/.../blob/main/docs/img/...`) rather than embedding them as
local site assets, so they were never part of the rendered site to begin with.
