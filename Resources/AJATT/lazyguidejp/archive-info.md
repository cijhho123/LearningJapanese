# Lazy Guide for Japanese Immersion (lazyguidejp) - markdown source

Source: <https://github.com/LazyGuideJP/lazyguidejp.github.io> (site:
<https://lazyguidejp.github.io/jp-lazy-guide/>).

The full markdown source of the *Lazy Guide for Japanese Immersion*, a community-maintained guide
covering Anki/Yomitan setup, per-medium immersion pipelines (anime, manga, visual novels, light
novels, gaming) on both PC and Android, ShareX-based mining, and dedicated Linux setup chapters.
English and Japanese versions of most pages are maintained side by side.

## Contents

46 markdown files, 377 KB: the repository's top-level `README.md` plus the 45 files under
`docs/jp-lazy-guide/`.

## What was excluded

Only the markdown source tree was taken from this repository. The same repository also contains a
`docs/img/` folder of setup screenshots that the markdown references by relative path (e.g.
`../img/anki-sync.png`) but does not itself store - those images are mirrored separately from the
built site in `../lazyguidejp.github.io/`, not in this folder.
