# morg.systems (Morgawr's zettelkasten) - offline mirror

Source: <https://github.com/Morgawr/morg-zettel> (site: <https://morg.systems/>).

A complete mirror of Morgawr's personal Japanese-learning zettelkasten, built with the Neuron
note-taking tool and published as a static site. The notes are personal study notes rather than a
structured guide - short essays, Q&A entries, and grammar/kanji observations accumulated over
several years of studying Japanese.

## Contents

231 files, 24 MB: 135 markdown notes, roughly 90 images and site assets under `static/`, and a
handful of repository/site-configuration files (the Neuron config, a GitHub Pages publish
workflow, `head.html`). Notes use Neuron's `[[double-bracket]]` wiki-link syntax between each
other (e.g. `[[4f5f4e00]]`), which resolves to real files in this same folder but renders as plain
bracketed text rather than a clickable link in a standard markdown viewer.

### Logged immersion hours

`Japanese-2022-in-Review.md` through `Japanese-2025-in-Review.md` contain four consecutive years
of the author's own logged immersion hours, broken down by medium (videogames, visual novels,
light novels, manga, anime, Anki), cross-posted from the author's r/LearnJapanese year-in-review
reports. The accompanying charts are in `static/` as `2022-review-graph*.png` through
`2025-review-graph*.png` (plus `moyase_2025_immersion.png`). This is one learner's actually-logged
hour data, rather than the rough community-estimate figures that immersion-hour totals are usually
based on.
