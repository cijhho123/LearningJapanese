## Notes on the EDRDG documentation specifically

The EDRDG's own `licence.html` (saved in `Dictionary format documentation (EDRDG - JMdict,
KANJIDIC)/`) states that in March 2000, Jim Breen assigned copyright of JMdict, EDICT,
ENAMDICT, COMPDICT, KANJIDIC2 and KANJIDIC to the Electronic Dictionary Research and
Development Group, and that this licence statement "applies to the following dictionary
files, the associated documentation files, and any data files which are derived from
them." In other words, the documentation in this folder carries the same licence terms
as the data files already present in `Resources/Vocabulary/JMdict (jmdict-simplified
JSON)/` and `Resources/Kanji/KANJIDIC2/` - format documentation only, no dictionary
entries duplicated.
