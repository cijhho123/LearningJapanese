# Sources and provenance - machine-readable data in `Resources/Kana/`

This file covers only the **structured data sets** added to this folder. The charts, workbooks,
videos and Anki decks that make up the rest of `Resources/Kana/` predate this file and are
documented in [readme.md](./readme.md).

Everything here is small. That is the nature of the subject: the kana system is finite, so the
useful data sets are measured in hundreds of rows, not hundreds of thousands. The value is that
they are *complete* and *authoritative* rather than large.

**Total size of the data sets in this file: 5.12 MB.** Core kana-system data (below) accounts for 0.22 MB; historical kana, loanword decoding and kana look-alike research add a further 4.9 MB.

## Notes for actually using these

- **The CLDR `.xml` files are ICU transliterator rules, not lookup tables.** They are ordered
  rewrite rules with context (`ッ}[カキクケコ] → k` means "ッ becomes k when followed by one of
  カキクケコ"), so reading them top-to-bottom as a mapping will give wrong answers. To *execute*
  them, feed them to ICU (`icu.Transliterator` in PyICU, `Intl`/ICU4J elsewhere). To *read* them,
  start with `Latin-Katakana.xml` - the comment block near the top is the clearest short statement
  of the Kunrei/Hepburn differences available.
- `Hiragana-Latin.xml` is only 961 bytes because it is a pipeline, not a table: it normalises, runs
  `Hiragana-Katakana`, then `Katakana-Latin`, then re-composes. The actual mappings live in
  `Latin-Katakana.xml` (which is declared `direction="both"`).
- **`kana-to-romaji (kunrei and hepburn).tsv` is a mechanical join** of the `KUNREITAB`,
  `KUNREITAB_H`, `HEPBURNTAB` and `HEPBURNTAB_H` string tables inside `common.py`. No entries were
  added, removed or edited; the header records this and `common.py` is kept beside it as the source
  of truth. Note that romkan's tables use `x` as the small-kana prefix (`xa` = ァ, `xtu` = ッ), so
  those rows are IME conventions rather than either romanisation system.
- `kana.json` includes the obsolete ゐ/ゑ/ヰ/ヱ under `type: other`, which matches the
  "Recognizing kana" Anki deck in this folder - useful if you want to diff the two.
- The two kana-frequency tables are not the same length (130 vs 104 rows). The gojuuon-ordered file
  is the complete run including six zero-count entries; the sorted file is shorter. Use the
  gojuuon-ordered one as the authoritative list.
- **The Unicode hentaigana code charts and the L2 proposal PDF are a matched pair, not duplicates.**
  The charts (`U1B000.pdf`, `U1B100.pdf`) are the terse, final, approved reference - codepoint, name,
  source-kanji cross-reference, nothing else. `Revised Proposal to Encode Hentaigana` is the same
  material with the historical argument attached (why these forms were used, when they stopped being
  used, why the 1948 hentaigana-naming ban happened). Read the proposal first if you want the story;
  use the charts to actually look something up.
- **The Higuchi (2022) paper is a copy of a paywalled journal article**, sourced from
  Deutsche Nationalbibliothek's public mirror rather than Springer directly, because the DOI landing
  page itself sits behind a login wall. If you need to cite it, cite the DOI
  (`10.1007/s12144-021-02664-w`), not this file.
- **NINJAL's two files are the same underlying 176 words in two shapes.** The PDF (`iikae-teian-1-4`)
  is the four historical rounds as originally published, with rationale per round. The HTML
  (`iikaegotou-dic`) is the same 176 words flattened into one alphabetical (五十音順) reference table
  with difficulty ratings - use the HTML if you just want to look a word up, the PDF if you want the
  committee's reasoning.
- **The NINJAL list and the Wikipedia list answer different questions and do not overlap much in
  practice.** NINJAL is Japanese bureaucratic/media loanwords judged confusing *for Japanese
  readers* (アカウンタビリティ, コンプライアンス) and gives a Japanese paraphrase. Wikipedia's list
  skews toward loanwords and wasei-eigo that are confusing *for English speakers because they look
  like English and are not* (マンション, コンセント). Use NINJAL for reading news/business Japanese,
  Wikipedia for avoiding embarrassing false-friend mistakes.
