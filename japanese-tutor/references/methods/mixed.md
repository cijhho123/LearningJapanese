# Method: Mixed (default)

No single profile driving the session. Pick per session from what the learner's
state actually says is needed.

This is the default because most of the four profiles are complementary rather
than competing, and committing to one on day one is a decision made with the
least information you will ever have.

## Teaching stance

**Ask by default, and read the room.** Push when they are learning a pattern; back off when they are reading for volume or clearly want an answer rather than a lesson.

## What genuinely combines

- Immersion + comprehensible input + SRS - all input-first with different scaffolds
- Any input method + structural explanation - explanation accelerates
  comprehension, it does not compete with it
- Anything + production practice
- Anything + JLPT as a periodic gap audit

## What genuinely conflicts - do not try to run both

| Conflict | Take |
|---|---|
| Isolated kanji course vs vocab-first | Vocab-first, with components taught reactively when a confusion fires. Doing both is doing kanji twice. |
| Frequency ordering vs JLPT/textbook ordering | Sequence by frequency, *tag* by JLPT. You can only sequence by one. |
| Strong Krashen (no output, no study) vs actually running an SRS | Be honest: take the interface position. Study can become acquisition. |
| Delayed output vs early production | Against a machine the anxiety objection largely evaporates. Start earlier than Refold says, later than a classroom would. |

## Selection rule for a session

In rough priority:

1. Overdue items with the lowest retrievability
2. An unaddressed confusable pair -> `kanji-discrimination`
3. The top recurring error from `weak_points` -> targeted drill
4. Production, if recall stability is lagging recognition badly
5. New material from the top-priority active resource
6. A generated `graded-passage` to tie the above together in context

Then pick the format to match the goal. Interleaving helps when the task is
telling similar things apart - and can actively hurt when the task is acquiring
a new word or pattern, where blocked practice wins. Block first, interleave once
there is something to discriminate between. See `exercise-types.md`.

## Switching

If the learner wants a single-method profile, `/japanese-tutor:configure` sets
it. Switching is cheap - the state is method-independent.
